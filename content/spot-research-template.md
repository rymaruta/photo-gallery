# 公式撮影地ガイド・1スポット調査票（編集用テンプレート）

**このファイルは調査のひな型であり、公開スポットのデータではない。** 1件につきコピーし、確認した事実だけ記入する。公開用JSONの型・入力値・画像条件は、採用する公式スポット実装（PR #143 `docs/spot-guide-2026-09-23.md` / `lib/data/spots.ts`）を正とする。

関連: [コンテンツ充実化・公開運用計画](../docs/content-enrichment-2026-09.md) / [既存の地域ページ](../docs/spot-master.md)

## 使い方

1. 個別の撮影地点を1つ選ぶ。地域名だけなら「地域案内」とし、スポット登録に進まない。
2. 「未確認」は未確認のまま残す。外部の資料を見ていないのに「確認済み」と書かない。
3. 出典は**項目ごとに**記録。トップページのURL1つで駐車場・撮影制限・座標まで全部確認したことにしない。
4. 画像の権利確認記録・撮影地点の証拠が揃うまで、画像を公開用JSONへ入れない。
5. レビュー後にだけ正式スキーマへ転記する。調査中の情報、実名が入った許諾メール、非公開GPS原本、私有地の詳しい位置はコミットしない。

## D. 行き方・変動情報の検証

| 項目 | 確認した内容 | 直接裏付ける公式URL | 確認日 | 期限・次回確認 |
|---|---|---|---|---|
| 公共交通 | 未確認 | | | |
| 車でのアクセス | 未確認 | | | |
| 徒歩ルート／標高差など | 未確認 | | | |

- 駐車料金・営業時間・運行時刻・天候・通行可否は頻繁に変わる。固定値で載せる必要がなければ公式情報へのリンクで案内する。
- 根拠を確認できない交通・安全情報をそれらしく記述しない。訪問者を未整備ルート、私有地、危険な崖際、立入禁止区域へ誘導しない。
- 出典に対して閲覧日だけでなく、**その情報が更新されていないか**を公開前にも確認する。

**自分で撮った写真**であっても、その写真が対象スポットの実際の景色か、撮影位置が一致するかを調べる。第三者の画像は「ネットに公開されている」ことを利用許可とみなさない。画像無しでも公式ガイドとして成立するレイアウトを使用する。

## G. 公開前のチェックリスト

- [ ] 地域ではなく個別地点として同一性が確認できる
- [ ] 正式名称、住所または公開可能な位置、公式資料が確認済み
- [ ] 固有の見どころと撮影向けの説明がある
- [ ] 事実と独自の撮影アドバイスを区別した
- [ ] アクセス／安全に関する表示項目は、項目単位の出典と確認日がある
- [ ] 画像を表示するなら、場所の対応、権利、クレジット、加工・配信の許可を確認済み
- [ ] 無関係な画像や生成画像を実景の証明として扱っていない
- [ ] 写真0件・画像無し・未ログインでもページの内容が成立する
- [ ] 既存の `/location/*` とURL/名称が衝突しない
- [ ] 既存の保存済み撮影地データへの影響をレビューした
- [ ] SEO用の説明が固有の内容で、架空のレビュー・件数・ランキングが無い
- [ ] スマホ幅とPC幅で実表示をレビューした
- [ ] 公開可否と実装PRのレビュー・承認が完了した

**すべてを機械的に埋めることが目的ではない。** 実データに入れるフィールドのみ裏付けを必須にする。PR #143の公開条件と食い違う場合は、採用済みの正式スキーマ・公開ゲートを正として調整する。
