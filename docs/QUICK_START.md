## 必要なもの

- **Node.js** 18以上（[公式サイト](https://nodejs.org/)からインストール）
- **Git**（[公式サイト](https://git-scm.com/)からインストール）
- **AWSアカウント**（アップロード機能を使う場合のみ）

---

## 5分で始める

### ステップ1: プロジェクトをクローン

```bash
git clone https://github.com/rymaruta/photo-gallery.git
cd photo-gallery
```

### ステップ2: 依存関係をインストール

```bash
npm install
```

### ステップ3: 開発サーバーを起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開くと、写真ギャラリーが表示されます！

## 💡 よくある質問

### Q: AWS設定なしで使えますか？

**A:** はい。写真の閲覧はAWS設定なしで使えます。アップロード機能を使う場合のみAWS設定が必要です。

### Q: どのドキュメントを読めばいいですか？

**A:** 
- **初心者**: [このガイド](./QUICK_START.md) → [初めてのセットアップ](./SETUP.md)
- **アップロード機能を使いたい**: [初めてのセットアップ](./SETUP.md)
- **本番にデプロイしたい**: [本番デプロイ](./DEPLOY.md) → [本番環境のセットアップ](./PRODUCTION_SETUP.md)（詳細）
