# Journey Photo — 海外の公的航空写真（完全無料・別ブランチ）

対象: `design/world-public-imagery-20260924`。日本版 `design/free-imagery-map-20260924` の**既存の1枚の地図**、公開写真/公式スポットピン、位置情報の保護、検索・保存を維持。公開/マージ/有料サービス契約は行わない。

## 海外の公的機関の実画像を地域別に取り込む

国ごとの地理院・地質調査所等が**Web配信まで無料で、商用用途が認められ、APIキー・カード・月額・従量課金を必要としない**と確認できたものだけを、個別のラスタソースとして追加する。配信元の画像が欠ける地域は、正規のデータがあるベース地図に戻す。地図に領海/行政/国境の線を描かない。プロバイダーの出典は常時表示。

### 米国 — このブランチでコードを追加

- 公的機関: USGS (U.S. Geological Survey) / The National Map、USDA NAIP。
- RESTラスタタイル: `https://basemap.nationalmap.gov/arcgis/rest/services/USGSImageryOnly/MapServer/tile/{z}/{y}/{x}`。ArcGISの順序は `z/y/x`。無料公開キャッシュの直接参照で、キー無し・契約無し。
- 実装上は本土48州の外接範囲（`[-125,24,-66,50]`、地形上の国境線ではない）だけ、画像ズーム9〜18で使用する。日本版GSIの実画像はそのまま継承し、写真/スポットピン、地名、操作系は同じ地図で動作する。ソースは地域/ズームで自動選択。
- この範囲指定は厳密な領域ポリゴンではなく、境界付近にはカナダ/メキシコも含まれる可能性がある。空中写真の欠損は提供元の条件に従い、架空の衛星画像で埋めない。
- **重要な制限**: このUSGSサービスにはアラスカのSPOT画像など第三者ライセンス制約があるため、このブランチではアラスカ・ハワイにサービスを広げない。取得可能な全画像を「無条件で再配布可能」と見なさない。正規出典を維持し、過剰なタイルダウンロードや独自キャッシュは行わない。
- [USGSの公式Webサービス一覧](https://apps.nationalmap.gov/services/) / [USGS ImageryOnly](https://basemap.nationalmap.gov/arcgis/rest/services/USGSImageryOnly/MapServer) / [USGS The National Mapの利用規約](https://www.usgs.gov/faqs/what-are-terms-uselicensing-map-services-and-data-national-map)

### その他の国 — 調査対象、現時点でアプリ内未実装

- **フランス：IGN**。公的な航空写真のデータセットは开放ライセンスの公開例があるが、常時大量タイルを商用SNSに表示する**APIサービス利用条件はデータ自体のライセンスとは別途確認**する。無料閲覧画面・試用枠だけでは要件を満たさないので、今回勝手に組み込まない。
- **その他：**各国の公的地理機関、オープンデータポータル、Copernicus Sentinel。衛星データが自由利用でも、そのタイルホスティング・処理・通信量まで無料とは限らない。
- 国ごとに `公的機関 → 実画像データの利用条件 → タイル配信の無償条件 → 画像がある地域/ズーム → 出典 → 実際の画像読み込みテスト` の順に通過させて登録する。

## 実スクショ／検証

- PRのGitHub Actionsは日本版を上書きせず、米国カリフォルニア州Big Surのテスト用座標 `#16/36.2704/-121.8081` で実Next.jsを起動してスマホ390×844とデスクトップ1280×800を撮影する。
- **ブラウザがUSGSから画像Content-TypeかつHTTP 200のラスタタイルを受け取った場合のみ、米国の実航空写真スクショと見なす**。無反応や通常地図しか撮れていない場合は未検証と明記する。
- テストだけのスポットはCIランナー内に生成し、公開台帳へは追加しない。日本版スクショは別PR #157の検証結果に残す。
- 日本/米国以外の地域では、現時点で無料の世界MODIS衛星モザイク（低解像度）または既存の通常地図のみになる。Google Earth並みの海外全域の細密画像ではない。
- 無料の「地図素材・公的サービス」の利用と、Journey Photo全体のクラウド/配信/ユーザー写真のストレージ料金は別。WebGL/CDN依存の公開前監査と公的配信サービスの現行条件を確認する。所有者の許可前に公開しない。
