## 概要

このアプリケーションは、AWS Cognitoを使用した認証システムを実装しています。
管理者のみがアップロード機能にアクセスできるように制限されています。

## 必要な環境変数

### ローカル開発環境

`.env.local`ファイルに以下の環境変数を追加：

```env
# AWS Cognito設定
NEXT_PUBLIC_COGNITO_USER_POOL_ID=ap-northeast-1_XXXXXXXXX
NEXT_PUBLIC_COGNITO_CLIENT_ID=xxxxxxxxxxxxxxxxxxxxxxxxxx
NEXT_PUBLIC_AWS_REGION=ap-northeast-1
```

**⚠️ 注意**: `NEXT_PUBLIC_COGNITO_IDENTITY_POOL_ID`は使用していません（このプロジェクトでは不要です）。

### 本番環境

`.env.production`ファイルまたは環境変数設定に以下を追加：

```env
NEXT_PUBLIC_COGNITO_USER_POOL_ID=ap-northeast-1_XXXXXXXXX
NEXT_PUBLIC_COGNITO_CLIENT_ID=xxxxxxxxxxxxxxxxxxxxxxxxxx
NEXT_PUBLIC_AWS_REGION=ap-northeast-1
```

## AWS Cognitoのセットアップ

### 1. Cognito User Poolの作成

1. AWSコンソールでCognitoサービスに移動
2. 「ユーザープールの作成」をクリック
3. 以下の設定で進む：
   - **サインインオプション**: ユーザー名とメールアドレスを選択
   - **パスワードポリシー**: 必要に応じて設定
   - **MFA**: オプション（必要に応じて有効化）
   - **アプリクライアント**: 新しいアプリクライアントを作成
     - クライアント名を設定
     - **認証フロー**: `ALLOW_USER_PASSWORD_AUTH`を有効化（重要）
   - **確認の手順**: メールによる確認を選択

### 2. 管理者グループの作成

1. 作成したユーザープールの「グループ」タブに移動
2. 「グループを作成」をクリック
3. グループ名: `admin`
4. 「グループを作成」をクリック

### 3. ユーザーの作成とグループへの追加

1. 「ユーザー」タブに移動
2. 「ユーザーを作成」をクリック
3. ユーザー名、メールアドレス、一時パスワードを設定
4. 「ユーザーを作成」をクリック
5. 作成したユーザーを選択
6. 「グループに追加」をクリック
7. `admin`グループを選択して追加

### 4. アプリクライアントの設定確認

1. 「アプリ統合」タブに移動
2. 作成したアプリクライアントを選択
3. 「認証フロー」セクションで以下が有効になっているか確認：
   - `ALLOW_USER_PASSWORD_AUTH` ✅
   - `ALLOW_REFRESH_TOKEN_AUTH` ✅

### 5. 必要な値を取得

設定が完了したら、以下の値を`.env.local`に設定：

- **User Pool ID**: ユーザープール一覧ページまたはユーザープールの詳細ページのURLに表示
- **App Client ID**: 「アプリ統合」タブ → アプリクライアント → クライアントID
- **Region**: ユーザープールを作成したリージョン（例: `ap-northeast-1`）

## 認証フロー

1. ユーザーが`/login`ページでユーザー名とパスワードを入力
2. Cognitoで認証を実行
3. 認証成功後、ユーザーのグループをチェック
4. `admin`グループに属している場合のみアップロード機能にアクセス可能
5. セッションはブラウザに保存され、次回アクセス時に自動的に認証状態を確認

## 保護されているページ

- `/upload`: 管理者のみがアクセス可能
- 管理者でない場合、自動的に`/login`にリダイレクト

## ヘッダーナビゲーション

- アップロードリンクは管理者のみに表示されます
- 一般ユーザーには表示されません

## セキュリティの考慮事項

### パスワードポリシー

Cognitoのパスワードポリシーを適切に設定してください：
- 最小文字数: 8文字以上
- 大文字、小文字、数字、記号の組み合わせ

### MFA（多要素認証）

必要に応じてMFAを有効化することを推奨します。

### セッション管理

- セッションはCognitoによって管理されます
- トークンの有効期限はデフォルトで1時間
- リフレッシュトークンにより自動的に更新されます

### APIキーとの併用

アップロードAPIは、Cognito認証とAPIキー認証の両方を使用します：
- クライアント側: Cognitoで認証済みの管理者のみがアクセス可能
- サーバー側: APIキーで認証（既存のセキュリティ）

## トラブルシューティング

### ログインできない場合

1. User Pool IDとClient IDが正しいか確認
2. アプリクライアントで`ALLOW_USER_PASSWORD_AUTH`が有効になっているか確認
3. ユーザーが正しく作成され、確認済みか確認
4. ブラウザのコンソールでエラーメッセージを確認

### 管理者として認識されない場合

1. ユーザーが`admin`グループに追加されているか確認
2. グループ名が正確に`admin`（大文字小文字も含む）か確認
3. ログアウトして再度ログインを試す

### 環境変数が読み込まれない場合

1. `.env.local`ファイルがプロジェクトルートに存在するか確認
2. 環境変数名が`NEXT_PUBLIC_`で始まっているか確認（クライアント側で使用するため）
3. 開発サーバーを再起動
