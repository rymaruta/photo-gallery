# Journey Photo Web — 全画面デザイン改良・実装/レビュー台帳

作成: 2026-09-24。対象: **Web版のみ**。現在の最終版モック `docs/mockups/README.md` と owner の `docs/redesign-2026-09.md` を一次資料とする。**この文書は「全画面のブラウザ確認が完了した」という報告ではない。**

## 全画面共通の設計判断

- 既存の深紺（`#050e17`）と青い主要操作を維持。写真と情報の階層を優先し、目立つグラデーション・根拠のない件数・飾りのための架空写真は追加しない。
- 表示は**「作品を楽しむ」「次の撮影地を探す」「訪問準備をする」「自分の作品/旅を管理する」**の役割で区別する。共通の文字階層・静かなカード・フォーカス・safe-areaは共通化し、全画面を同じカードだらけにしない。
- モバイルは下部5タブを維持。PCは各画面の幅・列を独立に扱い、スマホをそのまま横へ引き伸ばさない。ストーリー入口をホームへ戻さず、既存のマイページ配置を維持する。
- 公開データとレビュー用データは分離。実行中のPR #143／#147が持つ`content/spots.json`は**空**。公式スポットのカード・マップは正しく公開したスポットが入るまで実サイトに表示されない。デザイン試験には、許可済み画像または**ローカルテスト専用のfixture**を用い、本番JSONにモックを混ぜない。
- 公式撮影地点の公開座標とユーザー写真の公開用丸め済みGPSは区別する。撮影地名だけで他者の写真を公式ガイドへ自動的に紐付けない。既存保存の`/location/*`スラッグと公式スポットの`SPOT-`接頭辞を混同しない。

## 新しいマップの受け入れ条件

1. 公開公式スポット0件→**従来の写真マップだけが出る**。写真が0枚の時の読み込み中・失敗・空状態の違いも維持。
2. 公開公式スポットがあり、投稿写真0枚→**公式スポットのピンとガイドカードが出る**。写真側へ切り替えると正しい写真0件の案内が出る。
3. 確認された公開座標が無いガイド→**地図に架空のピンを立てない**。下部のガイドリンクからは詳細へ行ける。
4. 写真モードは旧どおりの約1kmの公開用GPS・公開写真だけ。公式ピンと写真ピンを見た目で区別する。
5. 地図のピンを押す／キーボードで選択すると、実在する公式スポットのカードと地図の選択が対応し、そのスポットの`/spots/[slug]`へ移動できる。
6. スマホの下部バー・ミニプレイヤー・ヘッダーが地図・カードや操作ボタンを覆わない。OSM帰属表示が見える。
7. PCは左にスポット一覧、右に地図。狭い画面と縦長画面で地図・リストの操作可能性を確認。

## 保存ボードの受け入れ条件

1. 公式スポットの代表写真は画像利用権限が確認済みの場合のみ表示。出典・ライセンスが必要ならクレジットも見える。
2. 写真0件の旧集約撮影地、無効な保存キー、非公開に戻った公式スポットも一覧で消えず、必要に応じてリンクを外し、「外す」を操作できる。
3. 保存元・保存解除・並び順・サーバーエラー・未ログインの振る舞いは変更しない。写真保存`/saves`／いいねした写真`/favorites`は別。
4. 320/375/390/430pxで長い名前、地名、権利者表示、キーボードフォーカス、削除ボタンとの干渉を確認。
